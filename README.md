# Game Library

Game Library — сайт для пошуку відеоігор за жанрами та перегляду цін у різних магазинах.

## Основні функції

* Пошук ігор.
* Категорії та фільтри.
* Інформація про гру.
* Посилання на магазини з цінами.
* Особиста бібліотека та відгуки.

## Ролі

* Гість — переглядає ігри.
* Користувач — зберігає ігри та пише відгуки.
* Модератор — перевіряє відгуки.
* Адміністратор — керує користувачами.

## Технології

HTML, CSS, JavaScript, SQL, GitHub.
